# Pepti Strength Cola

Landing page for Pepti, an HMB-infused zero-sugar cola with 3,000 mg of HMB per serving.

Static site, no build step: open `index.html` in a browser, or serve the folder with any static host (GitHub Pages, Netlify, Vercel).

- `index.html` – the page (inline CSS and JS)
- `assets/` – product photos

The email signup is front-end only. Connect it to an email service before launch.
